# 架构速记（改造作战地图）

> 本仓 fork 自 [itshen/learn-ai](https://github.com/itshen/learn-ai)（AGPL-3.0），改造为 AI×跨境电商学习站 study.waytoaic.com。
> 本文是改造期的作战地图：站点结构、后端缺口、必改文件清单。2026-08-10 起笔。

## 一、站点结构（纯静态，无构建工具）

```
index.html                  # 门户首页（营销页）
slides/
  home.html                 # 课程门户（篇章总览）
  learn.html                # Wiki 学习壳：左目录 + iframe 内容区，hash 路由
  course-data.js            # ★ 唯一课程数据源：COURSE.parts→topics→lessons
  lesson.css                # ★ 统一设计系统（:root CSS 变量）
  lesson.js / nav-inject.js # 内容页公共脚本（导航注入等）
  i18n.js                   # 三语框架；*.en.html / *.ko.html 各 237 页全量翻译
  <231 个知识点页>.html      # 每页独立、自包含交互
  exam-data-*.js / exam-all.html / certificate.html   # 考试 + 结业证书系统
  images/brand/             # 品牌资产（logo/二维码/头像）
  assets/                   # favicon、封面图、登录页图
```

- 路由：`learn.html#<file>.html`；hash 不在 course-data 里则回落到 `localStorage.__last` 或第一课
- 进度：未登录存 `localStorage.ai_course_progress_v1`（`{file:1, __last}`），登录后同步 `/auth/progress`
- 结构与内容解耦：**重组目录只改 course-data.js，内容页零改动**

## 二、后端接口面（均不在本仓，本地/静态部署下全部优雅退化）

| 脚本 | 接口 | 用途 | 改造去向 |
|---|---|---|---|
| auth.js | /auth/me /auth/progress /auth/search /auth/challenge* | 登录、进度同步、搜索 | 重写接 Supabase；搜索改纯前端 |
| track.js | /api/track /pv | 访问统计 | 下线或换自托管统计 |
| ask-alice.js | /alice/me /alice/questions | AI 答疑（Ask Alice） | 第一版下线，远期可接自己的模型网关 |
| challenge.js | /auth/challenge* | 7 天补贴营销系统 | 下线 |
| donor-board.js | （捐赠榜数据） | 赞赏展示 | 下线 |

## 三、必改文件清单（= 与 upstream 的冲突面，merge 时只裁决这些）

- `slides/learn.html` — 顶栏品牌位、郑重声明弹窗、交流群/二维码横幅、auth/challenge 注入点
- `slides/auth.js` — 后端指向重写
- `slides/course-data.js`（含 .en/.ko）— meta 品牌字段 + 目录树重组 + 新增知识点
- `slides/watermark.js`、`slides/share-card.js|css` — 水印与分享卡品牌
- `slides/track.js`、`slides/ask-alice.js`、`slides/challenge.js|css`、`slides/donor-board.js` — 下线/替换
- `index.html`、`slides/home.html` — 门户品牌与文案
- 品牌资产：`slides/images/brand/*`、`slides/assets/favicon.ico`、根目录 `qrcode_*.jpg`、`favicon.ico`
- 纪律：**新增内容一律加新文件，不动 upstream 内容页**

## 四、与线上站（xueai.app）的差距

- 本仓 231 课 vs 线上 276 课：build-*（实战篇）、opc-*（雷军创业课）、zero-q-* 等 45 页线上有、仓库未同步
- upstream 活跃维护（最近提交 2026-08-09），已配 `upstream` remote，**季度手动 `git merge upstream/main`**，冲突只会落在上面第三节清单内
